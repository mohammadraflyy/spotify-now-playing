## Yang baru

- **Chatbot bawaan untuk Twitch dan YouTube.** Penonton mengetik `!song` di chat, lalu bot membalas judul lagu yang sedang diputar. Ada juga `!lastsong` untuk lagu sebelumnya. Balasan dikirim ke platform asal pesan, jadi bisa dipakai di Twitch dan YouTube sekaligus. Perintah, balasan, dan cooldown bisa diubah di tab baru **Chatbot**, dan ada kolom **Coba** untuk melihat balasannya tanpa harus live.
  - **Twitch**: buat aplikasi sekali di Twitch Developer Console, lalu klik **Hubungkan Twitch** dan masukkan kodenya di `twitch.tv/activate`.
  - **YouTube**: buat OAuth client sekali di Google Cloud, lalu login dengan Google. Bot mulai membaca chat otomatis saat kamu live.
  - **TikTok** belum bisa, karena TikTok tidak menyediakan cara resmi untuk membaca atau membalas chat LIVE.
- **Riwayat lagu**: lagu terbaru sekarang ada di atas, dengan 10 lagu per halaman.

## In English

A built-in chat bot for Twitch and YouTube: viewers type `!song` (or `!lastsong`) and the bot replies on the platform the message came from. Set it up in the new **Chatbot** tab. The song history now shows the newest songs first, 10 per page.

## Install

Download `SpotifyNowPlaying-Setup-1.6.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
