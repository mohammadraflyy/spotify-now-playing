## Yang baru

- **Perintah chat buatan sendiri.** Di tab Chatbot, tambahkan perintah apa saja dengan balasannya, misalnya `!discord` dibalas dengan link Discord atau `!jadwal` dengan jadwal streaming. Berlaku di Twitch dan YouTube sekaligus, maksimal 30 perintah.
- **Akun bot terpisah.** Balasan bot bisa muncul atas nama akun khusus (misalnya TulusBot), bukan akun streaming-mu.
  - **Twitch**: hubungkan dengan akun bot, lalu isi nama channel streaming-mu.
  - **YouTube**: akun utama tetap dipakai untuk mendeteksi live dan membaca chat, lalu login akun bot untuk mengirim balasan.

## In English

Custom chat commands (for example `!discord` or `!schedule`) and an optional separate bot account for Twitch and YouTube, so replies come from a bot instead of your own account.

## Install

Download `SpotifyNowPlaying-Setup-1.7.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
