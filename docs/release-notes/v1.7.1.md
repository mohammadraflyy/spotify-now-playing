## Perbaikan

- Offset lirik khusus lagu yang diatur tepat setelah liriknya ditemukan kadang tidak tersimpan, lalu kembali ke 0 saat lagu itu diputar lagi. Sekarang yang tersimpan selalu pengaturan terbaru.

## In English

Fixes a per-song lyrics offset that could be lost if it was changed right after the lyrics were found.

## Install

Download `SpotifyNowPlaying-Setup-1.7.1.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai.
