## Yang baru

- **Request lagu dari penonton.** Penonton mengetik `!request judul lagu` di chat, lalu request-nya masuk ke antrian di tab baru **Request**. Request otomatis hilang dari antrian saat lagunya kamu putar, atau bisa ditandai selesai secara manual. Batas request per penonton dan panjang antrian bisa diatur.
  - **Twitch dan YouTube**: penonton mendapat balasan di chat, misalnya "request masuk: Tulus - Pamit (antrian ke-3)".
  - **TikTok**: listener baru untuk membaca request dari chat TikTok LIVE, tanpa balasan di chat. Butuh API key gratis dari Euler Stream, layanan pihak ketiga yang menyambungkan aplikasi ke TikTok LIVE.
- **Overlay antrian request** untuk OBS (`/requests`), supaya penonton tahu request-nya sudah masuk.

## In English

Song requests from viewers: `!request song title` in Twitch, YouTube or TikTok chat adds the song to a queue in the new **Requests** tab, with an OBS overlay that shows the queue. TikTok is read through a listener (needs a free Euler Stream API key) and gets no chat reply. A request leaves the queue automatically when you play that song.

## Install

Download `SpotifyNowPlaying-Setup-1.8.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
