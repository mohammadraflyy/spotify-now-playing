## Yang baru

- **Tampilan overlay request bisa diatur**, seperti kartu Now Playing: lebar, ukuran teks, jumlah lagu yang ditampilkan, sudut, latar (gelap, warna tetap, transparan), opasitas, dan warna aksen. Judul, nama penonton, platform, dan petunjuk cara request bisa ditampilkan atau disembunyikan. Preview langsung terlihat di tab **Request**, dan ukuran Browser Source untuk OBS dihitung otomatis.

## Lainnya

- Kebijakan privasi sekarang ada di `docs/PRIVACY.md`.

## In English

The song request overlay can now be customized like the Now Playing card (width, text size, rows, corners, background, accent, and which details to show), with a live preview and an automatic OBS size.

## Install

Download `SpotifyNowPlaying-Setup-1.9.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
