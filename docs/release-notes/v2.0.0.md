## Perubahan besar: chat sekarang hanya didengarkan

Aplikasi tidak lagi mengirim pesan ke chat mana pun. Twitch dan YouTube sekarang sama seperti TikTok: chat hanya dibaca untuk menerima **request lagu**, dan penonton melihat request-nya lewat overlay antrian.

- **Twitch tanpa login.** Cukup isi nama channel. Chat dibaca secara anonim, jadi Client ID, login Twitch, dan akun bot tidak diperlukan lagi.
- **YouTube dengan izin hanya baca.** Login Google masih dibutuhkan untuk mendeteksi live dan membaca chat, tapi izinnya sekarang hanya baca. Login YouTube yang sudah ada tetap berjalan; login ulang untuk memakai izin baru yang lebih sempit.
- Tab **Chatbot** berganti nama menjadi **Chat**.

## Yang dihapus

- Balasan di chat: `!song`, `!lastsong`, perintah buatan sendiri, cooldown, dan kolom Coba.
- Akun bot terpisah untuk Twitch dan YouTube. Login lama yang tidak dipakai lagi dihapus otomatis dari pengaturan.
- Channel Twitch yang sebelumnya terhubung tetap dipakai sebagai channel yang didengarkan.

URL `/api/now.txt` untuk chatbot lain seperti Streamer.bot tetap ada, sekarang di tab **File Teks**.

## In English

The app no longer sends messages to any chat. Twitch and YouTube are now listen-only like TikTok, used only for song requests. Twitch needs no login at all (just your channel name), and YouTube uses read-only access. Chat replies (`!song`, `!lastsong`, custom commands) and bot accounts were removed. The `/api/now.txt` URL for other chatbots stays, in the **Text files** tab.

## Install

Download `SpotifyNowPlaying-Setup-2.0.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
