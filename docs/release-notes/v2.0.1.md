## Donasi

Sekarang ada cara untuk mendukung pengembangan aplikasi ini lewat [Trakteer](https://trakteer.id/mohammadrafly/gift): tombol di tab **Aplikasi**, link di bagian bawah halaman pengaturan, dan menu **Dukung lewat Trakteer** di ikon tray. Tidak ada perubahan fitur lain.

## In English

You can now support development on [Trakteer](https://trakteer.id/mohammadrafly/gift): a button in the **App** tab, a link at the bottom of the settings page, and a **Support on Trakteer** item in the tray menu. No other changes.

## Install

Download `SpotifyNowPlaying-Setup-2.0.1.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
