## Menu lebih ringkas

- Urutan menu baru: **Beranda, Kartu Now Playing, Kartu Lirik, Kartu Request, Riwayat, Sumber Musik, Aplikasi**.
- Tab **Chat** digabung ke tab **Kartu Request**, di bagian **Chat yang didengarkan** di bawah pengaturan overlay. Antrian, pengaturan request, dan platform chat sekarang ada di satu tempat.
- Tab **File Teks & Cover** disembunyikan. File teks dan `cover.jpg` tetap ditulis seperti biasa; buka foldernya lewat klik kanan ikon tray → **Buka folder file teks**.

## In English

New menu order: Home, Now Playing card, Lyrics card, Requests card, History, Music source, App. The Chat tab moved into the Requests card tab (under **Chats to listen to**). The Text files & cover tab is hidden; the files are still written, and the tray menu still opens their folder.

## Install

Download `SpotifyNowPlaying-Setup-2.1.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
