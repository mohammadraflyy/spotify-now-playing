## Perbaikan

- Layout halaman pengaturan tidak lagi bergeser saat pindah tab. Sebelumnya, pindah dari tab yang panjang (misalnya Kartu Request) ke tab yang pendek (misalnya Riwayat) membuat scrollbar hilang, sehingga seluruh isi halaman bergeser sedikit ke samping.
- Pindah tab sekarang selalu mulai dari atas halaman.

## In English

The settings page no longer shifts sideways when switching between long and short tabs, and switching tabs now starts at the top of the page.

## Install

Download `SpotifyNowPlaying-Setup-2.1.1.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
