## Lebih stabil

- **Pengaturan tidak hilang lagi kalau file-nya rusak.** Setiap kali disimpan, pengaturan sebelumnya dicadangkan ke `config.json.bak`, dan file ditulis dengan aman supaya tidak kosong saat PC mati mendadak. Kalau `config.json` rusak, aplikasi memakai cadangannya, menyimpan file yang rusak untuk diperiksa, dan memberi tahu lewat notifikasi. Sebelumnya semua pengaturan diam-diam kembali ke awal.
- **Overlay tidak membeku kalau Spotify hang.** Pembacaan Spotify sekarang punya batas waktu. Kalau Windows tidak merespons, aplikasi menyambung ulang sendiri tanpa perlu di-restart.
- **Build lebih aman.** Versi library dikunci, dan setiap build menjalankan exe hasilnya untuk memastikan semua halaman dan API merespons sebelum dirilis.

## Baru di tab Aplikasi

- **Update sekali klik.** Kalau ada versi baru, klik **Update sekarang** di tab Aplikasi, di banner Beranda, atau di menu tray. Installer di-download dari halaman rilis GitHub, dicocokkan dengan checksum SHA-256-nya, lalu dipasang. Aplikasi tertutup sebentar dan terbuka lagi sendiri. Butuh *Beri tahu kalau ada versi baru* dinyalakan.
- **Ekspor dan impor pengaturan.** Pindahkan tampilan kartu, preset, lirik, overlay request, dan pengaturan chat ke PC lain. Login, token, Client Secret, dan API key tidak ikut.
- **Salin info diagnosa** untuk laporan masalah di GitHub Issues. Token dan key disamarkan otomatis.
- **File teks untuk OBS** (folder, format `nowplaying.txt`, dan URL `now.txt`) pindah ke sini, karena tab File Teks sudah disembunyikan.

## Perbaikan lain

- Tooltip ikon tray menampilkan "Jeda sebentar" dengan benar saat iklan.
- Teks di tab Kartu Lirik tidak lagi menyebut tab File Teks yang sudah disembunyikan.
- Screenshot README dan website diperbarui.

## In English

More stable: settings are backed up on every save and restored automatically if `config.json` gets damaged; reading Spotify has a timeout, so a hung player no longer freezes the overlays; dependencies are pinned and every build runs a smoke test of the exe. New in the **App** tab: one-click **Update now** (checksum verified, restarts by itself), settings **Export/Import** without logins or keys, and **Copy diagnostic info** for bug reports. Text file settings moved to the App tab.

## Install

Download `SpotifyNowPlaying-Setup-2.3.0.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
