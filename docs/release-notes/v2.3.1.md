## Perbaikan

- **Update sekali klik lebih andal.** Di beberapa kondisi, installer yang dijalankan aplikasi ikut tertutup sebelum sempat memasang update, sehingga tidak terjadi apa-apa. Sekarang installer berjalan terpisah dari aplikasi, jadi update selalu selesai dan aplikasi terbuka lagi sendiri.

Kalau kamu memakai v2.3.0 dan tombol **Update sekarang** tidak berhasil, download installer ini secara manual sekali saja. Update berikutnya akan berjalan otomatis.

## In English

One-click update is more reliable: the installer now runs independently of the app, so it can't be closed before it finishes. If **Update now** didn't work on v2.3.0, install this version manually once.

## Install

Download `SpotifyNowPlaying-Setup-2.3.1.exe` di bawah, lalu jalankan. Pengaturan dari versi sebelumnya tetap dipakai. Kalau muncul peringatan SmartScreen, klik **More info → Run anyway**.
