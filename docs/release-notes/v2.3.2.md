## Perbaikan: request lagu dari TikTok

- **Request dari chat TikTok sekarang masuk ke antrian.** Sebelumnya status TikTok sudah *Tersambung*, tapi semua chat diabaikan: Euler Stream mengirim chat sebagai JSON, sedangkan aplikasi hanya membaca format biner. Sudah dites dengan live TikTok sungguhan.
- Riwayat chat yang dikirim ulang saat baru tersambung tidak dibaca, supaya request lama yang sudah diputar tidak masuk lagi ke antrian.

## In English

Song requests from TikTok chat now reach the queue. Euler Stream sends chat as JSON text frames, which the app ignored before. Chat history replayed on connect is skipped, so old requests don't come back.

## Install

Download `SpotifyNowPlaying-Setup-2.3.2.exe` di bawah, lalu jalankan, atau klik **Update sekarang** di tab Aplikasi. Pengaturan dari versi sebelumnya tetap dipakai.
