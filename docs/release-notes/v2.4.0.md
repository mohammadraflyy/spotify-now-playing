## Request penonton diputar otomatis (Spotify Premium)

Request tidak perlu diputar manual lagi. Kalau login **Akun Spotify Premium**:

- Saat request masuk, aplikasi mencari lagunya di Spotify. Antrian menampilkan lagu yang ketemu. Request yang lagunya tidak ada di Spotify ditolak, dan lagu yang sama tidak bisa di-request dua kali walaupun ditulis berbeda.
- Sekitar 15 detik sebelum lagu yang sedang diputar selesai, request teratas dimasukkan ke antrian Spotify, lalu diputar setelahnya. Setelah request habis, Spotify lanjut ke playlist seperti biasa.
- Request dikirim satu per satu, jadi urutan dan hapus di tab **Kartu Request** tetap berlaku.
- Sumber musik tetap boleh **Spotify Desktop**. Login Akun Spotify hanya dipakai untuk mengontrol antrian.

Atur di tab **Kartu Request** → **Putar otomatis lewat Spotify**. Kalau sebelumnya sudah login Akun Spotify, login ulang sekali untuk memberi izin menambah antrian.

## Lagu selanjutnya

- Overlay baru `http://127.0.0.1:8765/next` menampilkan **Selanjutnya: Artis - Judul**, lengkap dengan nama penonton kalau itu request. Kalau tidak ada request, isinya lagu berikutnya di antrian Spotify. Overlay ini sembunyi sendiri kalau tidak ada lagu berikutnya.
- Juga ditulis ke file `next.txt` untuk source Text di OBS.

## In English

Viewer requests can now play automatically with a Spotify Premium login: each request is looked up on Spotify, and the top one is added to your Spotify queue about 15 seconds before the current song ends, then Spotify continues with your playlist. New **Up next** overlay (`/next`) and `next.txt`.

## Install

Download `SpotifyNowPlaying-Setup-2.4.0.exe` di bawah, lalu jalankan, atau klik **Update sekarang** di tab Aplikasi. Pengaturan dari versi sebelumnya tetap dipakai.
