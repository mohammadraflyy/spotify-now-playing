## Menu Kartu Selanjutnya

Overlay **Lagu selanjutnya** sekarang punya menu sendiri, **Kartu Selanjutnya**, di antara Kartu Request dan Riwayat. Sebelumnya panelnya terselip di bagian bawah tab Kartu Request.

- Atur lebar, ukuran teks, sudut, latar (gelap, warna tetap, transparan), opasitas, dan warna aksen, dengan preview langsung.
- Pilih apakah nama penonton yang me-request dan ikonnya ditampilkan.
- Salin URL, atau seret kotaknya ke OBS. Ukuran Browser Source dihitung otomatis.

## In English

The Up next overlay now has its own **Up next card** tab with size, background, color and display options and a live preview.

## Install

Klik **Update sekarang** di tab Aplikasi, atau download `SpotifyNowPlaying-Setup-2.4.1.exe` di bawah.
