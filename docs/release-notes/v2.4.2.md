## Perbaikan putar otomatis request

- **Pencarian lagu di Spotify tidak lagi ditolak.** Sebelumnya Spotify membalas *403: Insufficient client scope* untuk setiap pencarian, sehingga request tidak pernah ketemu lagunya dan tidak masuk ke antrian Spotify. Tidak perlu login ulang.
- **Lagu selanjutnya langsung menampilkan request.** Request yang masuk saat Spotify sedang bermasalah sekarang dicari ulang di latar belakang, bukan baru menjelang lagu selesai.
- Pesan error membedakan gagal mencari lagu dan gagal menambah ke antrian.

## In English

Fixed Spotify search being refused (403 Insufficient client scope), so requests now find their song and reach the Spotify queue without logging in again. Requests that arrived while Spotify had problems are looked up again right away, so Up next shows them.

## Install

Klik **Update sekarang** di tab Aplikasi, atau download `SpotifyNowPlaying-Setup-2.4.2.exe` di bawah.
