## Perbaikan koneksi TikTok

- **Koneksi chat TikTok tidak putus-sambung lagi saat chat sepi.** Sebelumnya koneksi dianggap mati kalau lebih dari 60 detik tidak ada pesan, lalu disambung ulang beberapa menit sekali, dan request yang masuk tepat saat itu bisa hilang. Sekarang aplikasi mengirim ping untuk memastikan koneksi masih hidup, dan sekaligus mencegah Euler Stream menutup koneksi yang diam.

## In English

The TikTok chat connection no longer drops and reconnects when chat is quiet for a minute; the app now sends a keep-alive ping instead.

## Install

Klik **Update sekarang** di tab Aplikasi, atau download `SpotifyNowPlaying-Setup-2.4.3.exe` di bawah.
