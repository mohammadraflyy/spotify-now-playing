## Info Spotify Premium

- Panel **Putar otomatis lewat Spotify** di tab Kartu Request sekarang menjelaskan bahwa fitur ini khusus akun Spotify Premium. Ini aturan Spotify: aplikasi hanya boleh menambah lagu ke antrian untuk akun Premium. Dengan akun Free, request tetap masuk antrian di aplikasi dan tampil di overlay, tapi diputar manual.
- Kalau Spotify menolak karena akunnya bukan Premium, pesan errornya menyebut itu dengan jelas. Error lain tidak lagi disebut sebagai masalah Premium.

## In English

The auto-play panel now explains that it needs Spotify Premium (a Spotify rule), and a Free account gets a clear error message instead of a generic one.

## Install

Klik **Update sekarang** di tab Aplikasi, atau download `SpotifyNowPlaying-Setup-2.4.5.exe` di bawah.
