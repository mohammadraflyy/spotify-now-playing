## Notifikasi request di overlay

Aplikasi tidak membalas di chat, jadi sekarang overlay request yang memberi kabar. Setiap request memunculkan pesan singkat selama 6 detik, lengkap dengan nama penonton dan platformnya:

- **Masuk:** Tulus - Pamit
- **Tidak ketemu di Spotify:** ...
- **Sudah ada di antrian** / **Baru saja diputar** / **Lagu terlalu panjang** / **Request ditolak**

Overlay yang disembunyikan saat antrian kosong tetap muncul sebentar untuk menampilkan notifikasi. Bisa dimatikan di tab Kartu Request → Tampilan overlay.

## Filter request

Di tab Kartu Request → Pengaturan:

- **Durasi:** tolak lagu yang lebih panjang dari batas (default 10 menit). Butuh login Akun Spotify.
- **Jeda:** tolak lagu yang sedang diputar atau baru diputar dalam sekian menit terakhir (default 30 menit).
- **Kata atau artis yang diblokir**, dicek pada teks request maupun lagu yang ketemu di Spotify.

## Request di riwayat

Lagu yang berasal dari request ditandai di tab Riwayat dengan nama penontonnya, juga di file `.txt` untuk deskripsi VOD: `21:03  Tulus - Pamit  (request budi)`.

## Perbaikan

- Login Akun Spotify Free sekarang juga mencocokkan request dengan lagu di Spotify. Hanya penambahan ke antrian Spotify yang butuh Premium.
- Pesan error merah di halaman pengaturan sekarang benar-benar berwarna merah.
- Website diperbarui dengan fitur-fitur baru.

## In English

Request notifications on the overlay (added, not found, already queued, played recently, too long, rejected), request filters (max length, replay gap, blocked words), and requests marked in the song history. Free Spotify logins now also match requests to the right song.

## Install

Klik **Update sekarang** di tab Aplikasi, atau download `SpotifyNowPlaying-Setup-2.5.0.exe` di bawah.
