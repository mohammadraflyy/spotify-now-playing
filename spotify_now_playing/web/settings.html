Mulai dalam 3 langkah

Cukup dilakukan sekali. Setelah itu tinggal buka aplikasi ini setiap kali streaming.

1

Putar lagu di Spotify

Buka Spotify Desktop di PC ini dan putar lagu apa saja.

2

Tambahkan kartu Now Playing ke OBS

Salin URL di bawah. Lalu di OBS buka Sources → + → Browser, tempel URL-nya, dan isi ukurannya 480 × 132.

3

Tambahkan lirik opsional

Caranya sama seperti langkah 2, dengan ukuran 800 × 340.

Belum pernah menambahkan Browser Source di OBS? Lihat caranya di sini
  1. Di OBS, buka panel Sources (kiri bawah), lalu klik tombol +
  2. Pilih Browser, beri nama (misalnya "Spotify"), lalu klik OK
  3. Hapus isi kolom URL, lalu tempel URL yang sudah kamu salin (Ctrl+V)
  4. Isi Width dan Height sesuai ukuran di atas, lalu klik OK
  5. Geser dan atur posisinya di layar preview OBS
  6. Kalau tampilannya belum berubah: klik kanan source → Properties → Refresh cache of current page

Chat yang didengarkan

Hanya membaca: tidak ada pesan yang dikirim ke chat. Bisa dipakai di beberapa platform sekaligus.

Twitch

Tanpa login. Chat Twitch dibaca secara anonim, cukup isi nama channel-mu.

YouTube

Login dengan Google

Login dipakai untuk mendeteksi live-mu dan membaca chat-nya, dengan izin hanya baca. Chat dibaca setiap 10 detik karena kuota gratis YouTube API terbatas.

Client ID Google (cukup sekali)
  1. Buka Google Cloud Console dan buat project baru.
  2. Di APIs & Services → Library, cari dan aktifkan YouTube Data API v3.
  3. Di OAuth consent screen, pilih External, isi nama aplikasi dan email, lalu tambahkan email akun YouTube kamu di Test users.
  4. Di Credentials → Create credentials → OAuth client ID, pilih Desktop app, lalu salin Client ID dan Client Secret ke bawah.

Selama aplikasi Google kamu masih berstatus Testing, Google membatalkan login setelah 7 hari, jadi perlu login ulang seminggu sekali.

TikTok

API key Euler Stream (gratis, cukup sekali)
  1. Daftar di eulerstream.com. Gratis, tanpa kartu kredit.
  2. Buka Dashboard, buat API key baru, lalu salin ke kolom di atas.

Euler Stream adalah layanan pihak ketiga yang menyambungkan aplikasi ke chat TikTok LIVE. Username TikTok dan API key-mu dikirim ke sana. Saat kamu belum live, aplikasi mengecek ulang setiap 3 menit.

Aplikasi

Aplikasi berjalan di system tray (pojok kanan bawah taskbar). Klik ikonnya untuk membuka halaman ini, klik kanan untuk menu lainnya.

Aplikasi langsung berjalan di tray tanpa membuka browser.

Mati secara default. Kalau dinyalakan, aplikasi mengecek halaman rilis di GitHub sehari sekali. Tidak ada data lain yang dikirim.

Folder data

Berisi pengaturan, login, cache lirik, dan catatan error (app.log).

File teks untuk OBS

File nowplaying.txt, title.txt, lyrics.txt, dan cover.jpg ada di folder ini. Pakai di OBS lewat Text (GDI+) → Read from file, atau Image untuk cover.

Format nowplaying.txt
Bisa pakai {title} {artist} {album}. Contoh: Now playing: {title} — {artist}

Perintah !song untuk chatbot

URL ini berisi teks lagu yang sedang diputar, dengan format yang sama seperti nowplaying.txt. Pakai di chatbot yang berjalan di PC ini, seperti Streamer.bot atau Mix It Up.

  1. Streamer.bot: buat Command !song, tambahkan sub-action Core → Network → Fetch URL dengan URL di atas, lalu kirim hasilnya lewat Twitch/YouTube → Send Message.
  2. Format bisa diganti lewat URL, misalnya ?format=Sekarang: {title} oleh {artist}.
  3. Nightbot dan bot cloud lain tidak bisa memakai URL ini, karena hanya bisa diakses dari PC ini.

Cadangan pengaturan

Simpan tampilan kartu, preset, lirik, overlay request, dan pengaturan chat ke satu file, untuk dipindah ke PC lain atau berjaga-jaga. Login, token, Client Secret, dan API key tidak ikut disimpan.

Ekspor

Laporkan masalah

Info diagnosa berisi versi aplikasi, status sumber musik dan chat, data lagu dari Spotify, dan isi terakhir app.log. Token dan key disamarkan otomatis. Tempel di GitHub Issues saat melaporkan masalah.
