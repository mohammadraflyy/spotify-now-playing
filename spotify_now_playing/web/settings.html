1 Spotify App

Buat app di Spotify Developer Dashboard (akun pemilik harus Premium).

  1. Dashboard → Create app → centang Web API
  2. Isi Redirect URI persis seperti di atas → Save
  3. Settings → User Management → tambahkan email akun Spotify kamu
  4. Copy Client ID (dan Secret bila mau) ke sini → Simpan

2 Akun & Sumber Data

Login sekali, token tersimpan otomatis.

Belum login
Login dengan Spotify

3 Tambahkan ke OBS

Atur tampilan, lalu seret kotak hijau ke OBS atau copy URL-nya.

⠿
Seret kotak ini ke jendela Preview OBSOtomatis jadi Browser Source 480×130 bernama "Spotify Now Playing"
  1. Cara manual: OBS → Sources + → Browser → paste URL
  2. Width 480, Height 130 → OK

4 Lirik ke OBS

Lirik tersinkron dari LRCLIB, tampil seperti di Spotify dengan latar mengikuti warna cover lagu. Perubahan di sini langsung ikut ke OBS tanpa ganti URL.

Lirik
Geser ke + kalau lirik telat, ke − kalau kecepatan.
⠿
Seret kotak ini ke jendela Preview OBSJadi Browser Source 800×300 bernama "Spotify Lyrics"
Mau teks biasa? Pakai lyrics.txt di folder output (baris yang sedang dinyanyikan).

5 File Teks & Cover (opsional)

Untuk OBS Text (GDI+) → Read from file, dan Image source untuk cover.jpg.

Placeholder: {title} {artist} {album}
Berisi nowplaying.txt, title.txt, artist.txt, album.txt, progress.txt, lyrics.txt, cover.jpg
