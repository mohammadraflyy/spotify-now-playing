Belum pernah menambahkan Browser Source di OBS? Lihat caranya di sini
  1. Di OBS, buka panel Sources (kiri bawah), lalu klik tombol +
  2. Pilih Browser, beri nama (misalnya "Spotify"), lalu klik OK
  3. Hapus isi kolom URL, lalu tempel URL yang sudah kamu salin (Ctrl+V)
  4. Isi Width dan Height sesuai ukuran di atas, lalu klik OK
  5. Geser dan atur posisinya di layar preview OBS
  6. Kalau tampilannya belum berubah: klik kanan source → Properties → Refresh cache of current page

Chatbot

Bot membalas perintah di chat live kamu. Misalnya penonton mengetik !song, lalu bot membalas judul lagu yang sedang diputar. Balasan dikirim ke platform asal pesan, jadi bisa dipakai di Twitch dan YouTube sekaligus.

Lagu sebelumnya

Perintah tambahan

Untuk info apa pun, misalnya !discord dibalas dengan link Discord, atau !jadwal dengan jadwal streaming.

Bisa pakai {user} {title} {artist} {album}. Kosongkan perintah untuk mematikannya, kosongkan balasan untuk memakai balasan bawaan.

Cooldowndetik

Jeda minimal sebelum perintah yang sama dibalas lagi, supaya bot tidak spam.

Akun bot terpisah (opsional)

Supaya balasan muncul atas nama akun bot (misalnya TulusBot), bukan akun streaming-mu:

  1. Buat akun Twitch baru untuk bot.
  2. Klik Hubungkan Twitch, lalu buka link kodenya di jendela browser yang login dengan akun bot (misalnya jendela incognito).
  3. Isi nama channel streaming-mu di bawah, lalu ketik /mod namabot di chat-mu supaya bot tidak kena slow mode.

Kosongkan kalau bot login dengan akun streaming-mu sendiri.

Client ID Twitch (cukup sekali)
  1. Buka Twitch Developer Console. Akun Twitch perlu mengaktifkan 2FA.
  2. Isi nama bebas. Di OAuth Redirect URLs isi http://localhost, Category pilih Chat Bot, dan Client Type pilih Public.
  3. Klik Create, lalu Manage, dan salin Client ID ke kolom di bawah.

YouTube

Login dengan Google

Bot membaca chat setiap 10 detik karena kuota gratis YouTube API terbatas, jadi balasannya bisa sedikit telat.

Akun bot terpisah (opsional)

Akun utama tetap dipakai untuk mendeteksi live dan membaca chat. Kalau akun bot login di sini, balasan dikirim atas nama channel bot. Tambahkan email akun bot ke Test users di Google Cloud, lalu jadikan channel bot moderator di live-mu.

Login akun bot
Client ID Google (cukup sekali)
  1. Buka Google Cloud Console dan buat project baru.
  2. Di APIs & Services → Library, cari dan aktifkan YouTube Data API v3.
  3. Di OAuth consent screen, pilih External, isi nama aplikasi dan email, lalu tambahkan email akun YouTube kamu di Test users.
  4. Di Credentials → Create credentials → OAuth client ID, pilih Desktop app, lalu salin Client ID dan Client Secret ke bawah.

Selama aplikasi Google kamu masih berstatus Testing, Google membatalkan login setelah 7 hari, jadi perlu login ulang seminggu sekali.

TikTok

TikTok belum menyediakan cara resmi bagi aplikasi untuk membaca atau membalas chat TikTok LIVE, jadi bot belum bisa dipakai di sana. Penonton TikTok tetap bisa melihat lagu yang sedang diputar lewat kartu Now Playing di layar.

Sudah pakai chatbot lain?

URL ini berisi teks lagu yang sedang diputar, dengan format yang sama seperti nowplaying.txt. Pakai di chatbot yang berjalan di PC ini, seperti Streamer.bot atau Mix It Up.

  1. Streamer.bot: buat Command !song, tambahkan sub-action Core → Network → Fetch URL dengan URL di atas, lalu kirim hasilnya lewat Twitch/YouTube → Send Message.
  2. Format bisa diganti lewat URL, misalnya ?format=Sekarang: {title} oleh {artist}.
  3. Nightbot dan bot cloud lain tidak bisa memakai URL ini, karena hanya bisa diakses dari PC ini.

Riwayat Lagu

Lagu yang diputar minimal 15 detik dicatat di sini. Berguna untuk deskripsi VOD atau menjawab "lagu tadi apa?". Riwayat hanya tersimpan di PC ini.
